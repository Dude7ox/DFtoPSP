# Character creation, classes, inventory and paper doll

Everything on these screens is read from the **original freeware data files** at
runtime - no converted or proprietary assets. A mod that replaces any of the
files below changes what the port shows, exactly like in classic Daggerfall.

| Screen | Original art | Original data |
|---|---|---|
| Race select | `TMAP00I0.IMG` (+`TAMRIEL2.IMG` index map) | `TEXT.RSC` 2000-2007 race texts, spoken ids 209-216 |
| Gender / class select | `CHGN00I0.IMG` | `CLASS00-17.CFG`, `TEXT.RSC` 2100+class |
| Class questions | `CHGN00I0.IMG` (scroll panel) | `TEXT.RSC` 9000 (40 questions), `CLASSES.DAT` |
| Custom class | `CUST00I0.IMG` | hit points 4-30, skill slots, adv/dis tables |
| Biography | `CHGN00I0.IMG` | `BIOG00-17T0.TXT` (12 questions, effect commands) |
| Bonus attributes | `CHAR02I0.IMG` | rolled stats + free pool 6-14 |
| Bonus skills | `CHAR03I0.IMG` | 28/18/13 bases + 6 points per skill group |
| Face | `CHAR01I0.IMG` + `FACE0rI0.CIF` / `FACE1rI0.CIF` | ten heads per race and gender |
| Name | `CHAR00I0.IMG` | `NAMEGEN.DAT` (11 banks of name parts) |
| Summary | `CHAR04I0.IMG` | finished document + reflexes 0-4 and face revisit |
| Inventory | `INVE00I0.IMG` | item icons from `TEXTURE.*` archives |
| Paper doll | `SCBG0rI0.IMG`, `BODY0r/1rI0/I1.IMG` | worn item art from `TEXTURE.*` |

## Readers added in this increment

- `src/core/ImgFile.{h,cpp}` - classic `*.IMG` / `*.CIF` / `*.RCI` images:
  12-byte record headers, uncompressed and RLE-2 pixel data, the headerless
  size table (`ITEM01I0`, full-screen 64000/64768-byte records, ...), embedded
  palettes (`CHGN00I0.IMG` carries its own 768-byte palette) and the per-file
  palette choice (`ART_PAL.COL` etc.).
- `src/core/TextRsc.{h,cpp}` - `TEXT.RSC` string bank with the classic
  formatting bytes resolved (`0xfd` line break, `0xf9`/`0xfb` prefixes, ...).
- `src/core/CharGen.{h,cpp}` - careers (`CLASS??.CFG`, 74-byte classic layout),
  biographies (`BIOG??T?.TXT` incl. `GP`, `IT`, `r?`, `RP/FT/RR/RD/MR/TH`
  effects), `NAMEGEN.DAT` name composition, the stat/skill rollout and the
  step machine shared by host and PSP.
- `src/core/ItemData{,Gen}.{h,cpp}` + `src/core/ItemDefs.h` - the 288 classic
  item templates (generated by `tools/gen_item_data.py` from the original
  table, MIT reference copies in `tools/ref/`), material value/weight/
  condition multipliers, equip slots and icon/paper-doll art resolution.
- `src/core/Inventory.{h,cpp}` - carried/worn items, twin slots, the classic
  starting kit (spellbook, gender clothing, class weapon, archer extras) and
  biography item grants.
- `src/core/PaperDoll.{h,cpp}` - the doll: nude body, clothed halves when the
  torso/legs are uncovered, race head, cloak interiors and worn items in
  classic draw order, plus the pixel-accurate click test.

## Classic details completed in this increment

- **Province map**: the race step now walks the cursor over `TMAP00I0.IMG` and
  decodes the province from the matching pixel of the index-only
  `TAMRIEL2.IMG` (pixel value = race id), followed by the classic
  description dialog and the spoken province id (DAGGER.SND 209-216).
- **Class questions**: ten of the forty questions of `TEXT.RSC` record 9000
  are drawn in order; each answer adds one weight to the warrior / rogue /
  mage column of the classic `kAnswerTable` (FALL.EXE v1.07.213 @0x0059820C).
  The triple is then looked up in `CLASSES.DAT` (results triples from offset
  18, header permutation in the first 18 bytes) exactly like the original,
  and the found class is offered in the accept / choose-manually dialog.
  Every accepted answer plays `SoundClips.Ignite` (DAGGER.SND 16).
- **Special advantages / disadvantages**: the custom-class screen offers the
  eleven classic advantages and eleven disadvantages with their
  `difficultyDict` point costs (increased magery x1/x1.5/x1.75/x2/x3 =
  2/4/6/8/10, immunity 10, regenerate health 14/10/6/2, forbidden material per
  material, phobia 4, critical weakness -14, ...), at most seven picks and a
  difficulty total clamped to -12..40. Picks mutate the career exactly where
  `CLASS??.CFG` stores them (resistance/immunity bits, forbidden materials,
  weapon/armor/shield bytes, rapid healing, regeneration, spell absorption,
  attack modifier, expertise skills) and are saved in the save file.
- **Reflexes**: the summary screen revisits face and reflexes
  (Very High / High / Average / Low / Very Low; critical chance
  `50-10*(reflex-2)` %) before accepting the character.
- **Save format v5** stores reflexes, the magery option and the full
  advantage pick list; readers still accept v1-v4.

## Derived numbers (classic formulas)

`damage=(STR-50)/5`, `encumbrance=STR*3/2`, `spell points=INT*advancement`,
`magic resist=WIL/10`, `to hit=AGI/10-5`, `hp mod=END/10-5`,
`max health=25+hp/level` at level 1 with the classic per-level roll afterwards.
Advancement multipliers come from `CLASS??.CFG` (Mage 1.04, Warrior 0.75, ...).
Races carry resistances/immunities (Breton magic, Nord frost, High Elf
paralysis) but **no attribute or skill modifiers - the classic game has none**.

## Controls

Host validation:

```
./build/host_main --root data --chargen-shots build/cg --seed 7 --race 1 --class 0
./build/host_main --root data --inventory-shot shot.bmp --race 3 --gender 1 --class 17
./build/test_core data          # includes the creation/inventory/save-v4 tests
```

PSP: a fresh boot (no `SAVE0.DFS`) starts in character creation - D-pad
chooses, X confirms, O goes back, Square rerolls the name list. In game,
Select cycles the windows; window 6 is the inventory (D-pad list/category,
X equips or removes). Start saves the character and the kit (save format v4;
v1-v3 saves still load, without a character).

## Scope notes and approximations

- The class-questions path of classic creation is not implemented; the port
  offers the 18 predefined careers plus the custom screen (documented).
- The custom screen edits hit points per level and the 3/3/6 skill slots.
  Special advantages/disadvantages are not offered (their classic cost table
  lives in the executable only), so difficulty points are unused.
- Custom classes skip the biography screen: the classic ships biography files
  for the 18 careers only (`BIOG00-17T0.TXT`).
- Starting equipment follows Daggerfall Unity's reading of the classic rules
  (`AssignStartingGear`): spellbook, short shirt + casual pants (equipped),
  class weapon and material, archer steel axe + 24 arrows, iron longsword for
  custom classes.
- Item icons use the `playerTextureArchive/Record` pairs with the classic
  adjustments (female weapons archive-1, variants, either-hand +1, katana +1);
  templates without player art fall back to their world texture.
- The PSP HUD derives `weaponMin/Max` and `lockpick` from the created skills
  (hand-to-hand and lockpicking values); combat otherwise unchanged.
